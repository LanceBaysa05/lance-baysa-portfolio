# Lance Baysa — Engineering Portfolio

A responsive personal portfolio built with Next.js, TypeScript and CSS.

## Run locally

```cmd
npm install
npm run dev
```

Open `http://localhost:3000`.

## Apply this update to the existing GitHub project

Replace the matching files and folders in the existing portfolio folder with the contents of this package. Then run:

```cmd
npm install
npm run build
git add .
git commit -m "Update portfolio content and projects"
git push
```

Vercel will automatically deploy the pushed update.
